# SparkX-Loop v0.2: Start Here

1. Open [`SparkX_Loop_v02_OneShot_Colab.ipynb`](file:///storage/emulated/10/Documents/Spark_X2.6_Loop/SparkX_Loop_v02_OneShot_Colab.ipynb) in Google Colab (or clone directly from `https://github.com/BaiTian6641/Spark-X2.6-Recursion`) and select the **G4 GPU runtime** (96 GB VRAM + 130 GB System RAM).
2. Add two secrets in **Colab Secrets**:
   - `HF_TOKEN` (or `HF_TOKEM`): used to upload full-finetuned stages (`warmup`, `R8`, `R12`, `R24`) and periodic intra-stage checkpoints (`SAVE_EVERY_STEPS=250`) to `https://huggingface.co/TassP0lar` (default repo ID: `TassP0lar/Spark-X2.6-4B-Loop-mHC`).
   - `OPENCODE_API_KEY` (or `OPENCODE_API`): used to query OpenCode (`https://opencode.ai/inference/openai/v1`) with `deepseek-v4-flash`, `haiku5.5`, and `mimo-v2.6-pro` for supervised CoT (`<think>...</think>`) synthesis and curriculum augmentation.
3. **Runtime > Run all**. Cell 1 clones/syncs `https://github.com/BaiTian6641/Spark-X2.6-Recursion.git`, runs [`setup_g4_env.sh`](file:///storage/emulated/10/Documents/Spark_X2.6_Loop/setup_g4_env.sh) (installing Unsloth Studio `unsloth` + `unsloth_zoo` + `bitsandbytes` + `cut-cross-entropy`), patches `XHToken/Spark-X2.6-4B` for **1M-context-safe fused SDPA** (`patch_spark_attention_for_long_context`), and launches the **23-hour Full Finetuning (`FULL_FINETUNE=True`)** run with `PagedAdamW8bit` + 130 GB System RAM sequence packing.
4. **Aggressive Looped Recursive Architecture**:
   - **Sublayer Dual-mHC (`mhc_attn` + `mhc_ffn`)**: Token-dependent FP32 RMSNorm + Sinkhorn Birkhoff routing before both attention and SwiGLU MLP across all 24 recurrent layers (`[4, 28)`, 96 Sinkhorn routing steps across 2 passes).
   - **Pass-Indexed Conditioning (`pass_routing_bias` + `pass_down`/`pass_up`)**: Per-pass Sinkhorn routing biases and zero-initialized SwiGLU deliberation adapters (`rank=16`, `max_passes=4`) so Pass 0 and Pass 1+ specialize functionally while sharing backbone weights.
   - **Multi-Scale Causal N-Gram Engram (`HashedBigramEngram`)**: Combines `2-gram (t-1, t)`, `3-gram (t-2, t-1, t)`, and `skip-2-gram (t-2, t)` embeddings with context-dependent sigmoid gating `ctx_gate(h_t)`.
   - **Unsloth-Style Token-Chunked Masked Cross-Entropy (`fused_masked_cross_entropy`)**: Computes CE over the 167,168 vocabulary in 512-token chunks only on supervised tokens (`labels != -100`), eliminating the multi-GB logits spike during long-context (`MAX_SEQ_LENGTH=4096`) full finetuning.
5. **Curated Multi-Source Reasoning + OpenCode CoT Mixture**: Streams and packs `<think>...</think>` traces from **Claude Fable** (`kelexine/fable-5-sft-traces`, `HelioAI/Claude-Fable-5-5500x`, `MoreThought/Fable-5.1-Max-Reasoning-Filtered-10000x`, `saidutta69/fable-5-premium-v2`, `armand0e/Fable-5-Chat`), **Claude Opus** (`Roman1111111/claude-opus-4.6-10000x`, `TeichAI/lordx64-claude-opus-4.7-max-cleaned`, `angrygiraffe/claude-opus-4.6-4.7-reasoning-8.7k`, `ronaldcmz/claude_opus_4.8_max_thinking_5k_v2`, `TeichAI/Claude-Opus-4.6-Reasoning-887x`), **GPT Astra / GPT-6 / GPT-5** (`FlaneAI/GPT-6Astra-scientific-research`, `Roman1111111/gpt-5.4-step-by-step-reasoning`, `vanty120/Gpt-5.4-Xhigh-Reasoning-2000x`, `TeichAI/gpt-5.1-high-reasoning-1000x`, `Manusagents/.../gpt55_thinking`), **GSM8K**, plus live **OpenCode** (`deepseek-v4-flash`, `haiku5.5`, `mimo-v2.6-pro`) traces.
6. After export, load and run inference with [`load_inference.py`](file:///storage/emulated/10/Documents/Spark_X2.6_Loop/load_inference.py), which automatically applies the 1M-context fused SDPA patch and supports fast per-visit KV-cached looped generation (`generate_cached` via `_VisitCache`).
